# Anthony Gonzalez

I work on practical open-source tooling around FreeBSD, OPNsense, network monitoring, and AI-assisted development.

## Projects

### [cline-freebsd-port](https://github.com/apg19590209/cline-freebsd-port)
Unofficial FreeBSD/OPNsense amd64 bootstrap for the Cline CLI, including native OpenTUI support and correct `/bin/sh` shell handling.

### [cline-linux-legacy-cpu](https://github.com/apg19590209/cline-linux-legacy-cpu)
Compatibility build workflow for running Cline CLI on older Linux x86_64 CPUs without AVX2. Validated with Cline 3.0.62 on Debian 13 using a reproducible clean-build process.

### [opnsense-devicemonitor](https://github.com/apg19590209/opnsense-devicemonitor)
Development fork of the OPNsense Device Monitor plugin with expanded device lifecycle, identity, history, and monitoring features.

### [opnsense-pppoe-ha](https://github.com/apg19590209/opnsense-pppoe-ha)
Automated CARP High Availability failover engine for OPNsense clusters operating behind dynamic PPPoE WAN sessions and G.fast/VDSL2 bridges (such as the Zyxel GM4100-B0). Includes dynamic Source NAT configuration overrides and lifecycle event tracking hooks.
